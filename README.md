# Project_5
<br>
<b>STM32F411 Multi Sensor Dashboard</b>
<br>
Moving beyond previous concepts, i have engineered this platform from clean sheet schematic to a dense, 4 layer routing solution. This custom 4-layer PCB was engineered to isolate high-frequency digital noise from the 100MHz STM32 processor, protecting the delicate micro-volt data of the MPU6050 and BMP280 sensors.
